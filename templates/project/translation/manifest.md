# Translation manifest

Source files remain at the repository root. Copy each filename unchanged into the target
language's `manuscript/` directory so source and translation pair mechanically.

Allowed status values: `not started`, `drafted`, `verified`, `human reviewed`.

- [ ] Target language and locale chosen
- [ ] Target-language glossary approved
- [ ] At least two paired style examples approved
- [ ] Dialogue and typography conventions recorded
- [ ] Epigraph and quotation rights and translation policy confirmed
- [ ] Final native-speaker literary review completed
